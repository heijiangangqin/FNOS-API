FNOS API 网关 · 使用文档

版本 1.5.2 ｜ 服务端口 9932 ｜ 最低系统 fnOS 1.2.0800 ｜ 最后更新 2026-10-27
一句话概括：本应用把飞牛官方的命令行 trim-cli 封装成 HTTP 接口，用 Bearer 令牌鉴权。 你在任何语言里发一个 HTTP 请求，就能读系统状态、管理文件、控制应用和 Docker，不用登 SSH。

1. 快速开始

关于安装：安装时不需要填任何东西，点安装即可。 装好后打开应用，页面会自动生成一个访问令牌并预填好，点「保存并进入」就能用； 想自己换一个也行。这个令牌既是进入网页的密码，也是调用接口的 Bearer 令牌， 之后随时可以在「设置」页查看或修改。

第一步：拿到访问地址和令牌

应用装在飞牛上，监听 9932 端口。地址取决于你从哪里访问：

访问位置地址
在飞牛桌面打开http://localhost:9932
局域网其它电脑http://飞牛的内网IP:9932（如 192.168.1.23）
通过 Tailscalehttp://100.x.x.x:9932

令牌由应用在首次打开时生成，之后可以随时改。两种查看方式：

  1. 应用「设置」页的「访问令牌」卡片，点显示（也可以直接在这里改）
  2. 用文件管理打开应用数据目录的 data/config.json，看 api_token 字段
进入页面必须输入令牌验证，验证通过才会显示设置页；浏览器会记住，下次自动验证。 换浏览器或清了缓存需要重新输入。确实忘了就用第 2 种方式查。

第二步：验证连通

# 不需要令牌，返回应用版本即表示服务正常
curl http://192.168.1.23:9932/api/health
{"success":true,"data":{"app":"fnos-api-gw","nas_host":"localhost","nas_port":"5666","scheme":"http","version":"1.5.2"}}

第三步：调用一个真实接口

curl -H "Authorization: Bearer 你的令牌" \
     http://192.168.1.23:9932/api/system/host-name
{"success":true,"data":{"hasUsers":true,"hostName":"ssnas","trimVersion":"1.2.0800"}}
网页端只提供一个「设置」页：查看令牌、改连接参数、完成授权、跑环境自检。 没有概览、文件浏览之类的功能页——那些能力通过 HTTP 接口调用，见第 5 节。

第四步：完成授权（必须）

认证通过后，如果还没有完成飞牛 OAuth 授权，页面会强制弹出授权窗口，不能关闭： 点「获取授权链接」→ 在新窗口打开并同意 → 把页面上的一次性 code 粘回来提交。成功后弹窗自动消失。

授权链接的地址跟随你的访问地址。后台是以 localhost 连飞牛本机的， 生成的链接里可能是 localhost，从别的电脑打不开；页面会自动把它替换成你当前访问用的主机名， 保证「授权地址」和「调用地址」一致。

2. 鉴权

除 /api/health 和 /api/setup 外，所有接口都要在请求头带令牌：

Authorization: Bearer <你的令牌>

也支持把令牌放在查询串里（方便浏览器直接打开，不推荐用于生产）：

http://192.168.1.23:9932/api/system/host-name?token=你的令牌
令牌等同于 NAS 的管理权限，不要写进前端代码、不要提交到 Git。 建议放在服务端环境变量里。怀疑泄露时，删掉 data/config.json 重启应用即可重新设置。

3. 返回格式

所有接口返回统一的 JSON 信封：

成功

{
  "success": true,
  "data": { ... }        // 业务数据，结构由上游决定
}

失败

{
  "success": false,
  "error": "缺少 path 参数",
  "errmsg": "上游原始错误",   // 可能没有
  "errno": 100060031,       // 可能没有
  "hint": "处理建议"          // 可能没有
}

上游的 errno 会被提取到顶层同名字段，不用再从 errmsg 文本里抠：

{"success":false,"error":"路径不存在或不可访问","errmsg":"... errno 4100","errno":4100}

error 是给人看的一句话，errmsg 保留上游原文，errno 用于程序判断。

判断成功请看 success 字段，不要只看 HTTP 状态码——某些上游业务错误会以 200 + success:false 返回。 errmsg 是飞牛原始报错，排障时最有价值。

4. 状态码与错误

状态码含义怎么处理
200请求已处理再检查 success 字段
400参数缺失或非法看 error，如"缺少 path 参数"
401令牌不匹配核对令牌；忘了就看 data/config.json
403被策略拦截如 /api/cmd 里调 media/login/改连接参数
409状态冲突操作与当前状态不符，如 SSH 已是目标状态、下载任务已完成、回收站里没有该文件
404接口或目标不存在核对路径。查询/删除不存在的文件、不存在的磁盘、非共享目录，都返回 404
409状态冲突如重复调用首次设置
428尚未设置令牌先在网页完成首次设置
500执行失败看 errmsg/errno，多为 NAS 侧限制
504超时换更小的查询范围重试
请求体上限 1MB，读取超时 60 秒。正常调用只有几 KB。注意：走慢链路（如 Tailscale 十几 KB/s）时，接近 1MB 的请求会先撞上 60 秒读超时而不是 1MB 上限，这类场景请在局域网内调用。
只读请求会自动重试一次。当底层代理出现瞬时连接故障（failed to call HTTP proxy）时， GET 接口会等 500 毫秒后重试一次。写操作不会重试，避免重复执行。

GET/api/file/trash/list?path=回收站

GET/api/file/recent/list—最近访问
GET/api/file/app-dir-list—应用数据目录
GET/api/file/sys-part-info—系统分区信息
POST/api/file/mkdirJSON：path新建目录。父目录不存在会自动创建
POST/api/file/rmJSON：path删除。目录会连内容一起删；目标不存在返回 404，不会假成功
POST/api/file/cpJSON：src dest_dir（目标目录，也接受 dest/dst）src dest复制到 dest 目录下（dest 必须是目录）
POST/api/file/mvJSON：src dest_dir（目标目录，也接受 dest/dst）src dest移动到 dest 目录下（dest 必须是目录）
POST/api/file/renameJSON：src name（新名，也接受 path/new_name）src name重命名
POST/api/file/share/addJSON：path name permset（必填）创建共享。permset 传 ACL 对象数组。permset 非法返回 400（不是 500）；失败时自动回滚，不会留下半成品共享

路径写法：飞牛用 /vol1/用户目录/... 或 /vol3/...。 注意 file/share/list 返回的 path 不带前导 /（如 vol3/1000/xxx）， 但两种形式传给 share/info 都认。 用 /api/system/vols 可以拿到实际卷号。不要写成 Windows 风格的反斜杠。
cp / mv 的目标参数是「目录」不是「新路径」。
{"src":"/vol1/1000/a","dest":"/vol1/1000/b"} 的结果是 /vol1/1000/b/a， 不是把 a 改名叫 b。要改名请用 /api/file/rename（name 只传新名字，不传路径）。 目标目录不存在时会创建失败，先 mkdir。

6. 通用命令通道

没单独封装的能力，走 POST /api/cmd，把参数按数组传给 trim-cli，覆盖全部 200+ 子命令。

curl -X POST -H "Authorization: Bearer 你的令牌" \
     -H "Content-Type: application/json" \
     -d '{"args":["file","trash","list","/vol1"]}' \
     http://192.168.1.23:9932/api/cmd

允许

  • 所有只读子命令
  • 带 --yes 的写命令（由你显式决定）

会被拒绝

  • media 影音相关
  • login / logout（请用 /api/auth/*）
  • --host --port --scheme --profile 等连接参数 —— 放在任何位置都会被拦（含 --profile=x 写法）
  • 含控制字符、超长、空字符串的参数
  • args 不是字符串数组（如传字符串、含数字、含 null）→ 400
想关掉这个通道（例如只给外部系统固定的几个只读接口）： 在应用「设置」里取消勾选「允许自由命令通道」，或 POST /api/config {"allow_passthrough": false}。

7. 多语言示例

curl（Linux / macOS / Git Bash）

TOKEN="你的令牌"
BASE="http://192.168.1.23:9932"

# 读 CPU
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/api/monitor/cpu"

# 建目录
curl -s -X POST -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"path":"/vol1/1000/新目录"}' "$BASE/api/file/mkdir"

Python

import json, urllib.request

TOKEN = "你的令牌"
BASE  = "http://192.168.1.23:9932"

def api(path, method="GET", body=None):
    data = json.dumps(body).encode() if body else None
    req = urllib.request.Request(
        BASE + path, data=data, method=method,
        headers={"Authorization": "Bearer " + TOKEN,
                 "Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=30) as r:
        return json.load(r)

cpu = api("/api/monitor/cpu")
print(cpu["data"]["cpu"]["busy"]["all"], "%")

现成的样例脚本在应用的 examples/ 目录： demo.py（49 项自检，分组打印结果）、curl.sh（30 个 curl 例子，分 7 组）。 令牌放 examples/token.txt 一行即可，无需改代码。

9. 写操作与安全

  • 参数缺失一律返回 400，并明确指出缺哪个字段，不会执行任何动作。
  • 密码错误返回 403，与参数错误（400）区分开
  • 危险操作需要密码预校验：卸载存储、停止存储池、格式化等要传 password（NAS 登录密码）。
  • 写操作不会自动重试，避免副作用执行两次；失败请自行判断后决定是否重发。
  • 不用传 --yes——命令行的写操作确认由本应用代你处理，调用方只管传业务参数。
  • 删除类接口会先核对目标：file/rm 和 file/share/del 对不存在的目标返回 404，不会出现"接口说删了、其实什么都没发生"的假成功。
  • 建议先用只读接口确认目标：比如 /api/storage/pools 看清 uuid，再调 /api/storage/mount。
  • IP 白名单（设置页可配）：留空即不限制；填了之后只有名单内的来源能访问，其余一律 403。 支持单个 IP 和 CIDR 网段，一行一个。见下方说明。

IP 白名单

项说明

/api/storage/format（格式化，数据不可恢复）、/api/user/del（删用户）、 /api/app/uninstall（卸载应用）、/api/power/reboot、/api/power/poweroff、 /api/network/ssh（关掉 SSH 可能让你自己连不上）。

10. 已知限制

现象原因与处理
file/search 部分关键字超时报错飞牛搜索本身是重查询。实测 key=test 约 7 秒/5010 条可成功， 但 backup、minecraft 这类会在大约 11 秒时被上游断开，重试也无效。 建议用更精确的关键字，或加 paths 收窄范围（实测 key=test 不带 paths 15.3 秒，带 paths=/vol1/1000 只要 1.5 秒）。
system/boot-on-power 等返回 errno 100060031this feature is supported only on official hardware。 自装机不支持，属正常。
monitor/battery 报错台式机没有电池，属正常。
monitor/proc-info 报 errno 100030001部分固件版本未开放该端点，换真实 pid 也不行。
file/share/info 报 errno 4101该路径不是共享目录（返回 404，响应里不带 errno 字段）。先用 file/share/list 拿真实共享路径。
baidu/* 返回 502未安装百度网盘插件，上游代理网关直接 502。装好插件并登录后可用。
download/info、download/files 返回 500上游 downloadcenter.task.getInfo 和 /ogh/ac/w 代理本身失败，与 download/ls、download/stat 无关。属上游限制，换任务 id 也一样。
file/usage?vol= 传不存在的卷号上游返回全零分类而不是报错，属上游行为。请先用 /api/system/vols 确认卷号。
network/ssh 返回 errno 33555719SSH 已经是目标状态时，上游会把它当错误返回。开关参数字段本身已正确透传。
偶发 failed to call HTTP proxy底层代理瞬时抖动。只读接口已自动重试一次；写操作需自行重试。
还有问题？ 打开网页控制台的「接口调试」页，可以直接选接口执行并看原始返回； 或在「登录授权」页点「诊断」，会输出 trim-cli 路径、伪终端可用性、session 目录可写性等自检信息。
