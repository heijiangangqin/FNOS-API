# 快速上手（3 步）

> 端口 **9932**。令牌 = 安装时你自己填的那串。

## 第 1 步：浏览器打开并输入令牌

```
http://192.168.1.23:9932
```

输入令牌 → 进入 → 若未授权，弹窗会强制要求完成授权（获取链接 → 同意 → 粘贴 code）。

## 第 2 步：调用一个接口

浏览器地址栏直接粘（令牌放 `?token=`）：

```
http://192.168.1.23:9932/api/system/host-name?token=你的令牌
```

或者命令行：

```bash
curl -H "Authorization: Bearer 你的令牌" \
     http://192.168.1.23:9932/api/system/host-name
```

返回：

```json
{"success":true,"data":{"hasUsers":true,"hostName":"ssnas","trimVersion":"1.2.0800"}}
```

## 第 3 步：换个接口看效果

```bash
# CPU
curl -H "Authorization: Bearer 你的令牌" http://192.168.1.23:9932/api/monitor/cpu

# 存储池
curl -H "Authorization: Bearer 你的令牌" http://192.168.1.23:9932/api/storage/pools

# 列目录
curl -H "Authorization: Bearer 你的令牌" "http://192.168.1.23:9932/api/file/ls?path=/vol1"
```

---

## 写操作要多一步

地址栏只能发 GET。新建目录这类 POST 要用命令行，带请求体：

```bash
curl -X POST \
     -H "Authorization: Bearer 你的令牌" \
     -H "Content-Type: application/json" \
     -d '{"path":"/vol1/1000/测试目录"}' \
     http://192.168.1.23:9932/api/file/mkdir
```

## 一句话看懂返回

| 字段 | 含义 |
|---|---|
| `success` | 只看这个判断成败，不要只看 HTTP 状态码 |
| `data` | 业务数据 |
| `error` | 给人看的一句话 |
| `errmsg` | 飞牛原始报错，排障用 |
| `errno` | 程序判断用，如 4100 = 路径不存在 |

完整接口清单见 `使用文档.html`。
